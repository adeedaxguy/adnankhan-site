Workflow & limitations

What this tool does

  • Reads portfolio/portfolio.json on load.
  • Lets you add, edit, delete, reorder items.
  • Saves edits to your browser's localStorage immediately.
  • Lets you export the merged data as portfolio.json.

What this tool does NOT do

  • It does not write to disk. The site is static; there's no server-side write capability.
  • It does not sync across devices. Edits on this device stay here until you export.
  • It does not regenerate the inner case-study HTML pages automatically. Run python3 scripts/generate_portfolio_pages.py after replacing portfolio.json.

Publishing workflow

  1. Edit items here. They save to localStorage.
  2. Click Export portfolio.json. Browser downloads the updated file.
  3. Replace portfolio/portfolio.json in the repo with the downloaded file.
  4. Run python3 scripts/generate_portfolio_pages.py to regenerate inner pages.
  5. Deploy: vercel --prod --yes.
  6. Done — site is live with the changes.

To make this a real backend

  • Enable Vercel KV in the dashboard, expose two serverless functions (/api/portfolio GET and POST), and replace the fetch calls in admin.js. About a half-day of work.
  • Or use Supabase with the JS client. Slightly more setup but multi-device sync comes free.
