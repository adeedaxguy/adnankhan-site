Publishing workflow
  1. Edit items here. They save to localStorage automatically.
  2. Click Export portfolio.json. Browser downloads the updated file.
  3. Replace portfolio/portfolio.json in the repo with the downloaded file.
  4. Run python3 scripts/generate_portfolio_pages.py to regenerate inner pages.
  5. Commit and push — Vercel auto-deploys in ~15 seconds.
