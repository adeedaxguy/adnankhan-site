Accessibility statement

I aim to make this portfolio usable with keyboard navigation, responsive zoom, readable contrast, semantic headings, visible focus, and meaningful alternative text.

Current approach

Core templates are reviewed on desktop, tablet, and phone. Interactive controls use native elements where practical, and reduced-motion preferences are respected by the new page system.

Known limitations

Some archived client screenshots may contain small text or brand contrast that belongs to the original project image. The surrounding case-study text provides context without requiring the screenshot to be read.

Diagnostic outputs

Automated audit results can be visually dense. They use live regions and structured headings, but complex generated reports may still benefit from browser reader modes or zoom.

Report a barrier

For an active Upwork relationship, report the affected URL and task through the existing Upwork message room so the issue can be documented and reviewed.
