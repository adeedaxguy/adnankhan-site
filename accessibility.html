Accessibility

Accessibility Statement

Lofts Studio aims to make this website clear, operable, and readable for visitors using keyboards, screen readers, zoom, reduced motion settings, and touch devices.

Last updated: June 21, 2026.

Plain English summary: the site is designed against WCAG 2.2 AA principles, checked with automated and manual QA, and includes optional visitor controls for larger text, higher contrast, underlined links, reduced motion, and relaxed spacing.

Our accessibility standard

We use the Web Content Accessibility Guidelines (WCAG) 2.2 as the working standard for this site, with AA as the practical target for public pages and key conversion flows. Accessibility is treated as part of design quality, not as a separate afterthought.

Visitor preference tool

The accessibility button opens optional preferences. No visual adjustment is applied until a visitor selects it. If a preference is selected, the site stores that selection in localStorage so the same browser can remember it on future visits. The reset button removes those preferences.

  • Larger text for easier reading.
  • Higher contrast for stronger text and borders.
  • Underlined links for clearer link recognition.
  • Reduced motion for visitors sensitive to animation.
  • Relaxed paragraph spacing for long-form reading.

Current SOPs

  • Keyboard checks for navigation, menus, forms, chatbot controls, and floating widgets.
  • Responsive checks across mobile, tablet, and desktop widths.
  • Color contrast review when adding new UI sections or theme changes.
  • Meaningful labels for buttons, links, form fields, and dialog controls.
  • Reduced-motion support for major animations and moving interface layers.

Known limitations

Some embedded third-party services, outbound pages, and historic client screenshots may not fully inherit this site's accessibility controls. Where possible, we keep those experiences optional and provide text alternatives or context around them.

Feedback and fixes

If you find an accessibility issue, email hi@lofts.studio or use the contact form. Please include the page URL, browser or device, and what you were trying to do. We review accessibility feedback as a priority support request.
