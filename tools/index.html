External tools I actually use

Built by other people · No affiliate links
External · Free Google

PageSpeed Insights

The first thing I run on any prospect’s URL. Real-user Core Web Vitals + a Lighthouse simulation with specific fix suggestions. Free, public, no signup.

Open PageSpeed Insights
External · Free Google

Rich Results Test

Paste a URL or JSON-LD snippet and see exactly which structured data Google will actually surface. The only way to stop guessing about Product, Review, and FAQ schema.

Open Rich Results Test
External · Free WebPageTest

WebPageTest

Run a real-browser test from a specific city on a specific device (Moto G4 on 4G is my favourite). Filmstrip view of what the customer actually sees in the first three seconds.

Open WebPageTest
External · Free Shopify

Shopify Theme Inspector

Chrome extension. Tells you which Liquid blocks on a Shopify storefront are slow, in milliseconds. The fastest way to find the one section eating your TTFB.

Open extension page
External · Free Squoosh

Squoosh

Local-browser image compressor with side-by-side preview. Avif, WebP, MozJPEG. The tool I use to drop hero images from 600 KB to 80 KB without visible loss.

Open Squoosh
External · Free Matrixify

Matrixify (Excelify)

The Shopify migration tool. CSV import-export for products, variants, metafields, customers, orders. Has a free tier that’s enough for sub-1000-SKU migrations.

Open Matrixify
